# Ví Của Tôi — trang pháp lý

Trang tĩnh cho ứng dụng iOS **Ví Của Tôi**. GitHub Pages deploy tự động thư mục `docs/`
của branch `main` mỗi khi có push (Settings → Pages → Deploy from a branch → `main` / `docs`).

| Trang | URL |
|---|---|
| Chính sách quyền riêng tư | https://a1darkwing.github.io/my-wallet-legal/privacy.html |
| Điều khoản sử dụng | https://a1darkwing.github.io/my-wallet-legal/terms.html |
| Hỗ trợ | https://a1darkwing.github.io/my-wallet-legal/support.html |

Bản tiếng Anh nằm trong `docs/en/` (cùng tên file), mỗi trang có nút chuyển VI | EN.
App mở bản `en/` khi đang chạy bằng tiếng Anh.

App mở các trang này trong app (Safari View) qua `AppConfig.legalBaseURL`.
Đổi URL ở đây thì phải đổi cả trong app và trên App Store Connect.
